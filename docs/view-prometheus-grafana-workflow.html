How Backend → Prometheus → Grafana work together

Beginner view of our CMF monitoring setup. Read the colored boxes left-to-right / top-to-bottom, then the numbered steps below.

You

Use the app / Swagger, and open Grafana to watch.

Backend

Your FastAPI on port 8989. Serves APIs and /metrics.

Prometheus

On port 9090. Collects numbers every 15 seconds and stores them.

Grafana

On port 3002. Turns stored numbers into easy charts.

Simple story (4 steps)

  1. You call an API (job card, production log, etc.). The backend does the work.
  2. Backend updates /metrics — silent counters like “how many requests” and “how long they took”.
  3. Prometheus scrapes /metrics every 15 seconds and keeps a history of those numbers.
  4. Grafana reads Prometheus and draws the dashboard so you can see rate, latency, and errors.
